# SimpleCommerce Frontend

A modern e-commerce platform built with Vue 3, Vite, Vue Router, and Pinia.

## Project Setup

```sh
npm install
```

### Development Server

```sh
npm run dev
```

### Production Build

```sh
npm run build
```

### Preview Production Build

```sh
npm run preview
```

## Project Structure

- `src/`: Source code
  - `assets/`: Static assets (styles, images)
  - `components/`: Reusable Vue components
  - `layouts/`: Layout components
  - `router/`: Vue Router configuration
  - `stores/`: Pinia stores
  - `views/`: Page components
  - `services/`: API services
  - `utils/`: Utility functions

## Features

- Multi-role support (Buyer, Seller, Admin)
- Product management
- Shopping cart
- Order management
- User authentication
- Admin dashboard
